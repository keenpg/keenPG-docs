# Installation

> Documentation version: 6.0

This section provides the installation and setup guidance for the keenPG Operator for PostgreSQL.

Use the following steps to prepare your environment and deploy the operator in a Kubernetes cluster.

## Prerequisites

Before installing the operator, make sure you have:

- A running Kubernetes cluster
- Access to the cluster with `kubectl`
- A namespace prepared for the PostgreSQL workloads
- Required storage and networking configuration for your environment

## Install the operator

1. Configure the required Kubernetes resources.
2. Apply the operator manifests to your cluster.
3. Verify the deployment is running successfully.
4. Confirm your PostgreSQL cluster is healthy and ready for use.

## Next steps

After installation, continue with configuration and operational tasks for your PostgreSQL environment.
